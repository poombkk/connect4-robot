This project is part of my senior project and is also an opportunity for me to challenge myself and improve my skills.

The project is based on the game Connect Four. Normally, two people are required to play Connect Four in real life. However, the goal of this project is to create a robot that can play and compete against a human player.

The project consists of four main phases:

Phase 1: Software Development
This phase mainly focuses on programming, user interface (UI) design, and developing the evaluation function. Most of the work in this phase involves back-end development.

Phase 2: Computer Vision
This phase focuses on developing a computer vision system that allows the robot to detect and understand the current state of the game board.

Phase 3: Mechanics and Control
This phase focuses on designing the robot’s mechanical components and developing its control system.

Phase 4: System Integration
This phase focuses on integrating the software, computer vision, and mechanical systems into one complete working system.

Current Status: Phase 1 is in progress.
